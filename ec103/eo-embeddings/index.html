Pasadena in embedding space

About

A satellite foundation model maps satellite observations of a location to a vector, an embedding. The models are pretrained without labels; locations with similar embeddings are similar with respect to the features learned in pretraining.

Visualizing embedding inputs: the data each model receives and its pretraining task. Explore: principal components, cosine similarity, k-means clusters, and individual dimensions. Change: cosine distance between embeddings of the same location in two years. Linear probes: out-of-sample linear prediction of physical and census variables from the embeddings.

All layers except the background imagery are precomputed. Keys 1–4 select views; Esc clears the similarity query.
