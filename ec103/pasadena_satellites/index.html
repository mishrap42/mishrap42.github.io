How this page works

  

    
Every image is computed live, as you pan, by Microsoft's Planetary Computer from the original Landsat, Sentinel-2, MODIS and NAIP files: the page asks for a set of scenes (a date window, a cloud filter), a band formula and a compositing rule, and the server returns map tiles. Median composites read every scene in the window, so a pane can take 5–15 seconds to fill; the spinner in its title says it is still working. Panes in one view move together, and the small ring shows where your cursor is in the other panes.

    
NASA GIBS serves the daily MODIS frames; EOX serves the Sentinel-2 cloudless mosaics. GEE code writes the Earth Engine script for the view you are on, the way you would do it for a project.

    
Keys: 1–5 switch views · space play/pause a time lapse or fire loop · ←/→ step frames · L labels · Esc close.

    
Caveats: Sentinel-2 files processed after 25 Jan 2022 carry a +1000 offset, which this page removes (Earth Engine's S2_SR_HARMONIZED does the same). Landsat values are Collection 2 Level-2 surface reflectance (scale 0.0000275, offset −0.2). NAIP is 8-bit aerial photography, not calibrated reflectance, so its index values are only comparable within one year.
